# Frontend - Vue.js + Bootstrap

Este directorio será la aplicación web para el panel administrativo de Agente CFE.

## Objetivo

- Panel web con autenticación JWT.
- Dashboard con métricas de dispositivos, SIMs, consumo y alertas.
- Vistas para usuarios, trabajadores, dispositivos, redes y reportes.

## Estado actual

Se crea la estructura base de la aplicación sin desplegar ni conectarla a producción.
