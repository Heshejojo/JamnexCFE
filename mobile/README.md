# Mobile - Flutter

Este directorio será la aplicación móvil para Android de Agente CFE.

## Objetivo

- Recopilar información disponible del dispositivo Android.
- Enviar datos de salud del equipo, SIM y consumo al backend.
- Operar de forma segura con autenticación y sincronización.

## Estado actual

Se crea la estructura base del proyecto Flutter sin configurar producción, MDM ni Android Enterprise.
